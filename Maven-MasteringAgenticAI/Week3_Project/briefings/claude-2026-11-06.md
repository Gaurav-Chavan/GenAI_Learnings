## Executive summary
- Pricing models differ, so direct comparison is hard: OpenAI Codex uses per-seat subscriptions (third-party sourced), Gemini CLI uses daily request quotas, and Mistral Large 4 uses per-token API pricing.
- OpenAI Codex has the widest price spread, from Free $0 to Pro tiers of $100/mo, $200/mo and $500/mo. All Codex pricing is third-party, and sources disagree on the Pro tier ($100/mo vs $200/mo).
- Gemini CLI's official page lists quotas but no subscription prices. The free tier gives 1,000 requests/day with a Google account and 250 requests/day with an API key.
- Mistral Large 4 has the only complete official pricing: $0.7/M input, $0.07/M cached input and $2.1/M output. Open weights were released on 2026-10-29.
- Recent momentum: Codex acquired Pierre Computer Company (2026-11-04) and is being positioned for non-technical workers. Gemini CLI shipped v0.66.0 (2026-11-05). Security reports touched both Codex (prompt adware) and Gemini-related tools.
